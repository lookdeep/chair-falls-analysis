# chair-falls-analysis — gh-pages branch

This branch holds the Jekyll source for the project landing page at <https://lookdeep.github.io/chair-falls-analysis/>. The actual analysis code, manuscript, and public data bundle live on the `main` branch.

Theme: [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) (remote_theme via Jekyll).

To build locally:

```bash
bundle install
bundle exec jekyll serve
```
